### Conclusiones
Antes de iniciar la Práctica 4, se desarrolló un prototipo (Layout Hi-Fi) a partir del sistema de diseño creado en Figma en la Práctica 3, estructurado mediante átomos, moléculas, organismos y patrones. Este sistema permitió establecer una base visual y funcional coherente que sirvió de guía durante todo el proceso de desarrollo en **Figma Make para publicar la versión web en producción**. A partir de ahí, el desarrollo se realizó mediante iteraciones progresivas guiadas por inteligencia artificial, refinando el diseño e incorporando mejoras respecto al prototipo original.

En general, se mantuvo la coherencia con el diseño inicial, aunque se introdujeron mejoras como la optimización del carrusel de novedades y eventos, la incorporación de secciones informativas en la página de inicio, ajustes en la página de “Nosotros” con sección de contacto y redes sociales, y mejoras funcionales en “Carta” y “Reservas”, incluyendo nuevas interacciones y elementos informativos. Las páginas legales se centraron principalmente en la mejora de la legibilidad y el formato del contenido.
